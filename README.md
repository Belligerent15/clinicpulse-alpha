# ClinicPulse Alpha

**Know before you go.**

ClinicPulse is a low-data web application that helps residents in Sekhukhune, Limpopo find nearby clinics and check important information before travelling.

## Features planned for Alpha

- Find clinics by name, village, or town
- View clinics on an interactive map
- See opening hours, contact details, and services
- Check clinic status: Open, Closed, Long queue
- Check chronic-medication availability
- Get directions
- Share clinic details on WhatsApp

## Technology

- HTML, CSS, JavaScript
- Python Flask
- SQLite
- Leaflet.js
- OpenStreetMap

## Important notice

ClinicPulse provides clinic and service information only. It does not provide medical diagnosis or treatment. In an emergency, contact emergency services or visit the nearest emergency facility.
